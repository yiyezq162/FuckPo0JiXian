# 安装、升级与恢复

本次产物为 0.8.3-preview，versionCode 18。应用包名为 app.fuckpo0jixian。Preview APK 非 debug、启用 R8 和资源压缩，沿用原开发签名策略。Android 9 起可安装；自动固定 Wi-Fi 身份需要 Android 12+ 的必要证据。

## 安装

构建打包后检查 dist/SHA256SUMS-runtime08（由版本 0.8.x 生成）。使用同证书 APK 覆盖安装保留数据，不卸载、不清数据。自建证书与他人发布包可能不同，签名冲突时保留原安装，先核对来源。本轮安全修复随 0.8.3-preview 提供；旧下载产物不含这些修复。CI 发布构建与真实设备安装验收分开，本轮不运行真实安装升级。

Mac 从 0.8.2 或更早版本发起自动升级，使用的仍是旧安装脚本；建议本次手动下载 DMG，完全退出旧应用后拖入“应用程序”替换。新脚本的安全回退只适用于由新版本发起的后续升级。

首次默认暂停且仅观察。「设置」页配置 token 并检查连接，「白名单」页按 capacity 编辑稳定槽位。先核对占用并授权，再绑定固定网络或分配本机唯一移动槽。其他手机选择自己的编号；不要共用写入槽。见 [详细设置](SLOTS.md)。

## v1 升级

原位 AtomicFile 迁移为 JSON v2，保留旧材料。旧固定身份待绑定，原编号和未初始化语义保留；旧移动授权先只读恢复核对，未知 Wi-Fi 默认关闭。暂停、观察状态不会因迁移自动打开。出现存储恢复提示时，不清数据、不卸载、不用默认状态覆盖文件；原文件和私有恢复材料需针对原因处理。

旧 APK 不认识 v2，不支持无条件降级。保留旧 APK 仅用于诊断参考，不能认为它能读取新状态。保存旧公网值不代表平台支持任意 IP 回滚。

## 模块

标准模式无需 root。可选模块 ZIP 绑定同次构建的 APK 签名，APK versionCode 必须与 module/module.prop 一致（当前双方均为 18），不是固定兼容 7。APK 与模块须同时更新，旧版模块会显示版本不匹配并降级为标准模式。模块协议仍为 1，没有 Wi-Fi 授权、token 或白名单决策。不要把握手等同于成功请求或业务连通。

需要安装时使用同次产物 FuckPo0JiXian-Runtime-0.8.3-preview.zip。模块详细边界见 [说明](../module/README.md)。

## 测试与停止

- 账户切换先持久保存暂停、无授权的新上下文，再写凭据；凭据或最终状态保存失败后保持安全状态。同 Token 保存保留配置并暂停。切换未完成时重新保存 Token，重新核对新账户槽位，不从旧账户恢复授权。
- Mac 自动替换等待退出最多约 60 秒；仍运行则中止。备份失败不删除原应用；复制失败恢复旧应用，恢复失败则保留 `.app.recovery.*` 中的 `backup.app` 与可能的 `failed.app`。查看用户数据目录 `updates/install.log`，先确认进程退出再人工处理；不要把部分复制目录当成完整安装，也不要先删除恢复材料。
- 全局保护使用概览“只读复核保护状态”；两次读取一致且保护条件成立才解除，成功后仍暂停。账户错配和不可读状态文件不能用此入口绕过。不要删除状态或 pending 强行恢复。

- 普通 UI / 视觉套件仅用于无真实凭据的专用模拟器；SafeTestRunner 拒绝真实手机上的重置套件。
- 请求绑定物理网络且不走代理，VPN / 系统代理不影响登记；VPN 禁止绕过时拒绝检查。出口证据不一致时拒绝登记，不把代理 IP 加入白名单。透明 root 代理不能仅凭系统标志证明不存在。
- 「概览」页暂停取消后续调度与进行中操作；已发出的 POST 不可撤销，未决状态需只读核对。关闭自动同步不删除远端记录。
- 模块问题先切标准模式，必要时暂停，再按管理器流程禁用模块。无需清除 APK 状态。
- 若进行网络切换测试，先记录原设置，结束后恢复；Doze 和厂商后台不保证固定发现时间。
- 可选前台服务仅提高后台存活概率，不承诺所有 OEM、Doze 或回收情形下常驻或自动恢复。
