# 安装、升级与恢复

## 安装

从 [Releases](https://github.com/yiyezq162/FuckPo0JiXian/releases) 下载，先用同一 Release 里的 `SHA256SUMS-*` 核对校验和。

- **Android**（9 及以上）：安装 `FuckPo0JiXian-<版本>.apk`。已发布的版本都用同一个证书签名，可以直接覆盖安装，不要先卸载或清数据。自己编译的包证书不同，装不上时保留原安装，先核对来源。
- **Mac**（Apple 芯片）/ **Windows**：见 README 的「桌面端」。

首次打开时检查处于暂停、只读状态。按 README「快速上手」添加 Token、授权槽位，再恢复检查。

## 升级

在「设置」里检查更新即可。下载后先核对 SHA-256，再交给系统安装：Android 由系统确认安装；Mac 替换应用后重新打开；Windows 用安装包就地升级。配置都会保留。

Mac 从 0.8.2 或更早版本升级时仍会用旧的安装脚本。这一次建议手动下载 DMG，完全退出旧应用后拖入「应用程序」替换。

不支持降级：旧版本读不懂新的状态文件。

## 模块（可选）

标准模式不需要 root。在「设置 → 运行模式」中选择「模块增强」，按提示点「安装」：应用下载同一 Release 的 `FuckPo0JiXian-Runtime-<版本>.zip` 并校验，再交给 Magisk / KernelSU 安装（KernelSU 直接打开安装界面；Magisk 请在「模块 → 从本地安装」中选择「下载」文件夹里的这个文件），重启后生效。也可以手动从 Release 下载后在管理器里安装。

模块只接受同一证书签名、且不比它更旧的 APK。应用内更新 APK 后，模块会继续工作；模块较旧时「运行模式」里会提示「更新模块」，管理器也会通过 `updateJson` 提示更新。说明见 [模块说明](../module/README.md)。

停用模块：先在应用里切回标准模式，再到管理器里禁用或卸载模块。不需要清除应用数据。

## 出问题时

- **概览显示「需要处理」**：先看提示原因，再点「只读复核保护状态」。复核只读取 Po0，不会重发上次的写入。通过后检查仍保持暂停，确认槽位后再恢复。
- **「本地数据无法读取」**：原文件已被保护，不会被覆盖。不要清除应用数据，保留现场后反馈问题。
- **暂停**：在「概览」暂停会取消后续检查和进行中的操作。已经发出的写入无法撤回，下次检查会先只读核对。关闭自动同步不会删除 Po0 上的记录。
- **反馈问题**：用「记录 → 导出调试信息」（IP 只保留前两段，不含 Token）。不要公开原始状态文件、接口链接、Token 或「导出本机分工」的内容。
