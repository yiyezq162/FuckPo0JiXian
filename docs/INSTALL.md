# 安装、真机测试与回退

## APK 0.4.0-preview

从 [Release](https://github.com/yiyezq162/AllowMate/releases/tag/v0.4.0-preview) 下载 `AllowMate-0.4.0-preview.apk`。这是非 debug 优化包，仍为开发签名预发布；Android 9 起可安装，Android 16 之外的兼容性尚未完整验证。

下载校验文件和所列附件后运行 `shasum -a 256 -c SHA256SUMS-runtime04`；只下载 APK 时，用 `shasum -a 256 AllowMate-0.4.0-preview.apk` 与校验文件中该行比较。

同包名、同证书可以覆盖安装保留数据。签名冲突时不要直接卸载；自建 debug 证书通常与发布证书不同。应用没有凭据导出与云备份，卸载或清数据会丢失本机凭据、密钥和槽位归属记录，但不会删除平台白名单。

## 另一台手机的推荐顺序

1. 先用标准模式和只读查询：手机本地输入 token 或官方接口链接，点击 Po0 页“检查连接”，不会新增或替换网段。
2. 查看容量和已有条目。家宽需已在白名单内；如果已经固定，沿用原家宽槽位。第二台手机选择独立空闲槽位，不与原手机或其他更新器共用。
3. 配置保存只修改本机并暂停。确认后开启自动同步、到首页恢复检查，才进入真实写入阶段。家宽未固定时必须在对应家宽网络完成安全初始化。
4. 观察一次前台检查，再做网络切换和后台检查。切网去抖约 15 秒，检查至少间隔 2 分钟；省电策略可能继续延迟。记录真实请求时间和读回结果，不把配置保存或限频提示当同步成功。
5. 完成后恢复原 Wi-Fi、移动数据及同步设置。不要为测试更改默认数据 SIM、清除未知白名单或影响其他设备的槽位。

只测试 UI 可使用 Po0 → 高级选项 → 本机演示模式；切换会清除本地关联、槽位配置和快照，但不改平台。已配置的手机不应随意切换。

## 可选运行模块

标准模式无需 root 或模块。先完成基本检查，再考虑使用已有 KernelSU / Magisk 环境测试模块增强，不需要为此刷内核或安装额外框架。

1. 安装同版本 APK，在管理器安装同一 Release 的 `AllowMate-Runtime-0.4.0-preview.zip`，按提示重启并首次解锁。
2. APK Po0 页选择“模块增强”。模式保存、helper 握手和 APK 实际请求完成是不同状态；每个 helper 代次先完成只读请求，随后才按原同步设置运行。
3. 模块只监听事件与有限唤起，网络和 token 留在 APK。APK 不申请 su；撤销 APK 的 su 权限不能当作禁用模块。
4. 管理器 Action 可做一次只读诊断；最近人工检查或历史连接不证明持续在线。失联时到管理器核对安装/启用状态。
5. HyperOS 可能需要自行允许本应用自启动。深 Doze 下仍可能降级，不承诺即时同步或低耗电。

当前模块只支持主用户 0、APK versionCode 4 与匹配签名。KernelSU 有条件性真机验证，Magisk 未完成真机验收。见 [模块说明](../module/README.md)。

## 暂停与回退

- 首页暂停检查取消调度及进行中的请求，保留配置；已发往平台的请求不能靠暂停撤销，需要只读核对结果。
- 关闭自动同步回到仅查询，不删除白名单。移除本机连接删除本机 token 和槽位配置并暂停，平台条目不变。
- 模块异常先切标准模式，必要时暂停 APK，再在管理器禁用/卸载 `allowmate_helper`，按提示重启。只禁用模块不会暂停标准模式任务。
- Android 强行停止会阻止后台工作，直到用户主动打开；模块不会绕过强停。
- 模块回退不需要清数据或卸载 APK，不建议强行降级；旧版可能不理解新版字段。

提交问题前移除 token、鉴权 URL、真实网段和设备标识，不要上传原始账户或 root 日志。
