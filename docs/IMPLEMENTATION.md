# 0.5 稳定槽位改造报告

本轮完成代码、v2 原位迁移、Compose 交互、演示、确定性测试和构建。未发布、推送、合并或运行真实账户写入。用户后续授权 ADB 手机测试，因此增加了受保护的升级/权限观察，仍不登记代理出口。

## 产品结果

按平台 capacity 展示稳定槽位，每槽可备注、固定/移动/保留、本机/其他设备/外部管理。家庭与公司名称自行填写，先明确接管授权，再绑定当前 SSID/AP/安全类型；授权 AP 上公网变化可以跨 /16 自动更新对应固定槽。一台手机最多一个自动移动槽，未知 Wi-Fi 默认关闭。其他设备槽在其自己的手机上独立授权。

未知、缺权限、同名新 AP、歧义和安全降级不会自动认领固定身份。现场手动固定更新独立于持久绑定，重新探测、预览、确认并受相同写入门禁约束。已覆盖但位于别槽显示迁槽受阻，不假装更新成功。移动槽出口被绑定为固定网络时提示后续覆盖缺口，临时保留由用户独立选择。

当前 Po0 与五槽演示都经 LayoutSync 执行，旧双槽/预算接口退出产品 UI 和 Controller 授权入口。演示包括两个固定网络、本机移动、另一设备、保留与无编号占用，以及重拨、通勤、公司、未知 AP、缺权限和冲突。

## 安全与迁移

v1 的非默认编号、未初始化和旧 pending 语义保留；固定身份不自动生成，旧移动权限先核对且未知 Wi-Fi 默认关闭。原文保留、AtomicFile 提交，失败/未知版本不写回空状态。备注/布局保存没有远端请求。切换账户/演示和清除凭据不会保留旧账户写权。

基线仅来自明确授权、有效 pending 或写后核验，历史出口不授予覆盖权。每轮一个目标，写前持久意图，定向 POST 后核验响应与 GET；丢响应只读恢复不重放。非目标保护、容量、限频、账号、配置、暂停、会话与身份变化均受门禁。单槽冲突不全局停机；鉴权/结构/存储/无法确认副作用进入全局保护。

保留无 CAS 边界，不声称最后一刻并发原子安全。旧 APK 不保证能读新状态；保存旧 IP 不是平台回滚。Wi-Fi 权限依据已核对官方 API31+/SDK36 文档，见 [槽位说明](SLOTS.md)。后台脱敏、旧版本或证据不足时保留手动/只读，不强制后台定位。

## ADB 手机结果

在用户追加授权后，对现有小米 Android16 安装进行保留数据覆盖升级；未卸载或清数据。原状态为暂停、无 token、无槽位计划，因此只证明实际安装迁移可读，不能证明真实已配置槽位升级。

单独 opt-in 的升级检查通过，未发 HTTP。系统 dumpsys 中 VPN 相关请求不能证明 APK 有活动 VPN；实际无 app-visible VPN 时未尝试平台请求，VPN 拦截真机验收仍 UNKNOWN。

WifiInfo 只读测试：未授权、撤销授权均正确不可用；临时授予精确位置后，非前台测试仍不可用，明确由 ADB 打开前台后可用身份断言通过（绑定实际 Network，HTTP=0，不打印或持久绑定 SSID/BSSID）。这证明本机本次前台读取，不证明自然后台、所有 ROM 或完整固定自动写入。ActivityScenario 在该机未正常完成的尝试已作废，不计入通过结果。

结束时恢复原 fine/coarse 拒绝状态，位置总开关、Wi-Fi/移动数据/代理配置未改动；原插电常亮=3、熄屏超时=600000ms 保持。最终覆盖安装非 debug 0.5.0-preview，保持应用暂停；未导入账户凭据、未登记任何 IP、未安装模块。测试 instrumentation 包保留，普通重置套件仍受 SafeTestRunner 保护。

## 后续真机补测与凭据导入（2026-09-27）

用户再次要求使用 ADB 手机测试，并明确要求填写 token。复用此前指定的本机私密 Po0 实例凭据，源文件权限 600，不修改源文件、不回显值；经 ADB stdin 进入 app 私有临时文件，由已门控的 importPrivateCredential 使用 Keystore 加密验证并删除明文。导入测试通过，手机 credential.enc 权限 600，临时文件不存在。

随后仅运行单独授权的 readPlatformOnly：测试通过，真实 GET 返回 capacity=5、entries=2（均有槽号），国内与 API /24 一致。仅观测模式，无 POST、无新增写权、无 pending；不能从出口一致推断不存在透明代理。原 40 条本机历史未因本次测试清空。

最终换回本次校验和对应的非 debug Preview，通过原生界面检查：加密 token 状态显示、五个稳定编号槽位均可滚动到、槽位编辑用途/管理者/备注与取消入口存在。打开编辑后取消，未保存接管授权。保持“OBSERVE＋暂停”，网络与位置权限不变，不运行普通真机重置/demo 套件。真实固定槽自动写入仍未验收。
